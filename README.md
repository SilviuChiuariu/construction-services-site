# 🏗️ Construction Services Site

A simple construction services website developed using HTML, CSS, JavaScript and Python.

## 🚀 Features

* Dynamic navigation between pages
* User registration and verification
* Video section
* Interactive canvas drawings
* Construction-related information and services
* Custom HTTP server written in Python

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Python
* JSON

## ▶️ Running the project

Clone the repository:

```bash
git clone https://github.com/SilviuChiuariu/construction-services-site.git
```

Start the server:

```bash
cd server_web
python server_web.py
```

Then open:

```text
http://localhost:5678
```
